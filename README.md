# Beyond Website

The website of Beyondia, a country of ideas.

Plain static HTML, CSS and one image: no build step. Open `index.html` in a browser, or publish the folder with any static host (GitHub Pages, Cloudflare Pages, Netlify).

## Pages

- `index.html` — home and the map of the site
- `stories.html`, `storyangel.html`, `storyfactor.html` — stories
- `conclusions.html` — conclusions of the treatise
- `ideology.html`, `principles.html`, `rules.html` — ideology
- `plans.html` — plans
- `technologies.html`, `techsales.html`, `techbot.html` — technologies
- `community.html` — community
- `creator.html` — the creator

Shared styles live in `beyondia.css`.
