Beyond Sales

A local business-to-business outreach platform, managed from a browser control panel.

  • Python
  • MySQL
  • AI
GitHub · Beyond-Sales

What it does

  • Keeps a mail queue and a permanent log of everything sent, in MySQL.
  • Scrapes company websites for context and contacts, honouring robots.txt and a minimum pause between requests.
  • Sends automatically within limits, and every start asks you to confirm the current limits.
  • Tracks replies from the mailbox, reading it without changing it, and keeps the promising ones as leads.
  • Helps draft messages with AI, but never sends anything itself: only a person sends.
  • Runs from a browser control panel, and from the terminal.
